Model Context Protocol (MCP) Server

Connect Claude Desktop, Cursor, or Cline to ThinkDome dynamic sandbox tools.

Claude Desktop Integration

Add the following configuration to your claude_desktop_config.json file to expose ThinkDome's dynamic tool registry directly into your Claude app:

{
  "mcpServers": {
    "thinkdome": {
      "command": "/home/sandbox/ThinkDome/venv/bin/python",
      "args": [
        "/home/sandbox/ThinkDome/think",
        "mcp",
        "--site",
        "personal"
      ]
    }
  }
}
HOW TO CONNECT
  1. Locate your Claude config file at:
    • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
    • Windows: %APPDATA%\Claude\claude_desktop_config.json
  2. Paste the configuration block above into the config file.
  3. Restart the Claude Desktop app.
